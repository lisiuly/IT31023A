# IT31023A 正倒计时语音播报钟 — 现有固件规格 (V1.x)

> 基于 `DEMO/` 目录下实际代码逻辑整理，GPL815P 系列 6502 CPU，gp65cc 工具链。
> 本文档描述当前固件**实际实现的功能**，供后续对比新规格书及修改参考。

---

## 一、硬件配置

| 项目 | 配置 |
|------|------|
| MCU | GPL815P 系列 6502 核 |
| 主频 | 2MHz（`D_SYS2M` / `D_CPUSysClkDiv1`） |
| LCD | 6 COM × 48 SEG |
| 背光 | PA1 PWM 输出，频率 1kHz，源时钟 256kHz |
| 语音模块 | UART 串口控制，PA5 控制模块电源通断 |
| 电池检测 | ADC (PB7) 模拟输入 + LVD 多级电压检测 |
| 充电检测 | PA3 (外电插入，输入上拉检测)、PB0 (充满指示，低有效) |
| 按键 | 6 个独立按键，PB1~PB6，低有效 |
| 看门狗 | 硬件看门狗，主循环持续喂狗 |

## 二、按键定义

| 按键 | I/O | 键值常量 | 键值 |
|------|-----|---------|------|
| **- 键** | PB1 | `D_DownKey` | `0x02` |
| **+ 键** | PB2 | `D_UpKey` | `0x04` |
| **闹钟键** | PB3 | `D_AlarmKey` | `0x08` |
| **正/倒计时键** | PB4 | `D_TimerKey` | `0x10` |
| **时钟键** | PB5 | `D_TimeKey` | `0x20` |
| **开关键** | PB6 | `D_PowerKey` | `0x40` |

- 去抖周期：4 个扫描周期（`C_KeyDebounce=4`）
- 长按判定：255 个扫描周期（`C_LongKey2Sec=255`，约 2 秒）
- 快加/快减间隔：16 个扫描周期（`C_FastAdd=16`，约每秒 8 次）
- 关机态仅保留 PB6（电源键）唤醒

## 四、操作模式详解

### 4.1 正常时间模式

| 操作 | 功能 | 语音播报 |
|------|------|---------|
| 短按**闹钟键** | 循环查看闹钟 1→2→3→1；首次短按播放"闹钟查看" | "闹钟查看" |
| 短按**正/倒计时键** | 若计时值=00:00 → 开启**正计时**；若已设值 → 开启**倒计时** | "开启计时" |
| 短按**时钟键** | 无操作 | — |
| 短按**开关键** | 背光亮度循环：1→2→3→1（3 档，**无"灭"档**） | — |
| 短按**+ 键** | 音量加 (0→1→2)，上限 2 | — |
| 短按**- 键** | 音量减 (2→1→0)，下限 0 | — |
| 长按**时钟键** | 进入**时钟设置**（年份闪动） | "日期设置" |
| 长按**闹钟键** | 进入**闹钟设置**（开关阶段） | "闹钟设置" |
| 长按**正/倒计时键** | 若计时未运行 → 进入**计时设置**；若正在运行 → 无操作 | — |
| 长按**开关键** | 切换开关机状态 | — |

### 4.2 时钟设置模式

- **进入**：正常模式下长按时钟键
- **退出**：保存后自动退出，或约 5 秒无操作自动返回

| 操作 | 功能 |
|------|------|
| 短按**时钟键** | 依次切换：**年 → 月 → 日 → 时 → 分 → 保存并播报** |
| **+ / - 键** | 当前字段 ±1；长按快加/快减 |
| 切换月份 | 自动校验日期是否超限，超限则修正为当月最大天数 |
| 保存时播报 | 进入时阶段 → 播"时间设置为"；退出设置态 → 播完整"年月日时分，设置成功" |

| 字段 | 范围 | 说明 |
|------|------|------|
| 年 | 00~99 | 对应 2000~2099，屏显 "20xx" |
| 月 | 1~12 | 自动处理闰年 2 月（28/29 天） |
| 日 | 1~当月最大天数 | 随月/年联动 |
| 时 | 0~23 | 24 小时制 |
| 分 | 0~59 | — |
| `R_TimeFlashSet` 常量 | `D_SetYear=0x01 → D_SetMonth=0x02 → D_SetDate=0x04 → D_SetHour=0x08 → D_SetMinute=0x10 → D_SetTimeMax=0x20` | 左移推进 |

### 4.3 闹钟设置模式

- **进入**：正常模式下长按闹钟键（**当前代码不区分闹钟开/关，一律进设置**）
- **退出**：3 组全部设置完后退出，或约 5 秒无操作自动返回
- **组数**：3 组（闹钟 1/2/3），`R_CurrentGroup` 索引 0~2

| 操作 | 功能 |
|------|------|
| 短按**闹钟键** | 依次切换阶段：**开关 → 时 → 分 → 天制 → 下一组/退出** |
| 开关阶段 | + / - 键切换当前闹钟组开/关（`R_AlarmOnOff` bit0=组1, bit1=组2, bit2=组3） |
| 小时阶段 | + / - 键调节 0~23 |
| 分钟阶段 | + / - 键调节 0~59 |
| 天制阶段 | + / - 键循环 0=每天 / 1=单休 / 2=双休（`R_DispAlmDay[group]`） |
| 完成一组 | 若为组 0 或组 1 → 切换到下一组，重置为开关阶段；若为组 2 → 退出设置 |

| 常量 | 值 | 含义 |
|------|------|------|
| `D_SetAlm` | `0x01` | 开关阶段 |
| `D_SetAlmHour` | `0x02` | 闹钟时 |
| `D_SetAlmMinute` | `0x04` | 闹钟分 |
| `D_SetAlmDay` | `0x08` | 闹钟天制 |
| `D_SetAlarmMax` | `0x10` | 最大阶段标记 |

- 闹钟查看模式下（非设置态短按闹钟键），首次播放"闹钟查看"后置 `D_AlarmView_Played` 标志，后续短按不再重复播放

### 4.4 计时模式（正/倒计时）

- 计时值范围：0 分 0 秒 ~ 60 分 0 秒

| 操作 | 条件 | 功能 | 语音 |
|------|------|------|------|
| 短按计时键 | 计时值=00:00 | 开启**正计时** (`D_Timerstatus_just`) | "开启计时" |
| 短按计时键 | 计时值≠00:00 | 开启**倒计时** (`D_Timerstatus`) | "开启计时" |
| 短按计时键 | 正计时运行中 | 暂停 (`D_Timerstatus_justpause`) | "暂停计时" |
| 短按计时键 | 倒计时运行中 | 暂停 (`D_TimerPausedCountDown`) | "暂停计时" |
| 短按计时键 | 正计时暂停中 | 继续正计时 | "继续计时" |
| 短按计时键 | 倒计时暂停中 | 继续倒计时 | "继续计时" |
| 长按计时键 | 计时未运行 | 进入计时设置（分钟闪动） | — |
| 长按计时键 | 计时运行中 | ? 无操作（仅 `RTS`） | — |
| + / - 键 | 设置模式 | 调节分钟 0~60 | — |
| 正计时到 | 60:00 | 停止并触发响铃 | 闹铃 |
| 倒计时到 | 00:00 | 停止并触发响铃 | 闹铃 |

- **注意：当前代码中并没有"短按切换正/倒计时"、"长按清零"、"暂停时短按时钟键继续"这些功能。**
- `R_TimerFlashSet` 仅用 `D_TimerSet=0x01` 和 `D_SetTimerMax=0x02` 两个值

### 4.5 关机模式

| 操作 | 功能 |
|------|------|
| 进入 | 长按开关键（`Enable_LongPowerKey`） |
| 关机动作 | 关闭 LCD（偏压/电荷泵/VLCD/显示驱动）、UART、ADC、TM0 定时器、PWM 背光、语音模块电源 |
| 关机态显示 | 全灭 |
| 唤醒源 | 仅 PB6（电源键）可唤醒（`P_IO_KeyChange_Ctrl2 = 0x40`） |
| 唤醒后 | 重新初始化 LCD (`F_LCD_Initinal`)、ADC (`ADC_Init`)、TM0、UART、语音模块 |
| 关机态主循环 | 进入 Green 休眠模式（32kHz + LCD 关 + 2Hz 时基），降低功耗 |
| 低电自动关机 | 低电报警播完后等待 5 秒自动调用 `F_SystemPowerOff()` |

### 5.2 闪烁规则

| 对象 | 条件 | 周期 |
|------|------|------|
| 时钟冒号 `T_Col` | 正常走时 | 0.5 秒亮 / 0.5 秒灭（`R_flash_Temp` 控制） |
| 设置态字段 | 正在设置的数码管位 | 0.5 秒灭 / 0.5 秒亮 |
| 低电图标 | 低电状态 | 全灭 ? T_T4 单格闪 |
| 充满图标 | 充满状态 | 全灭 ? T_T4 单格闪（但 4 格框常显） |
| 充电动画 | 充电中 | 每 0.5 秒递增一格，4 格满后回第一格循环 |
| 语音图标 | `R_Uart_OpenTime ≤ 5` | 闪烁提醒即将关闭 |

### 5.3 闹钟关闭时的显示

- 闹钟关闭的组：时分位显示空白（`0xAA` 全灭数码段），冒号 `T_ACol` 隐藏
- LCD 更新标志 `D_LcdChangeUpdate` 用于区分"闹钟值变化"和"每秒定时刷新"

## 七、电源管理

### 7.1 电池检测

| 电量档位 | 条件 | 显示格数 |
|------|------|---------|
| `D_BatLevel1` | >3.3V（约 99%） | 3 格 |
| `D_BatLevel2` | >3.0V（约 66%） | 2 格 |
| `D_BatLevel3` | >2.4V（约 33%） | 1 格 |
| `D_LowPower` | <2.4V | 闪烁（低电报警） |

- 每秒调用 `F_DC_Det()` 检测一次
- ADC 使用 PB7 作为模拟输入，参考电压 2.0V

### 7.2 低电处理流程

```
检测低电 → 确保语音模块就绪 → 播报"低电报警"1次
→ 固定等待 5 秒（128Hz × 640 ticks）→ 自动关机
```

- 充电插入后立即取消低电自动关机流程
- 开机后第一次循环重新检测电池（清除旧低电状态）

### 7.3 充电检测

| 状态 | 检测方式 | 显示效果 |
|------|---------|---------|
| 未充电 | PA3=0 | 按电量格数显示 |
| 充电中 | PA3=1 | 流水灯动画（每 0.5 秒递增一格，循环） |
| 充满 | PB0=0（低有效） | 4 格框常显 + T_T4 单独闪烁 |

- `R_Charge` 标志位：`D_LowPower=0x01`, `D_Charge=0x02`, `D_Full=0x04`

### 7.4 休眠模式

| 模式 | 进入条件 | CPU 时钟 | LCD | 唤醒源 |
|------|---------|---------|-----|------|
| Green 模式 | 关机态主循环空闲 | 32kHz | 关 | PB6 按键 + 2Hz 时基 |
| Standby 模式 | 预留（`F_StandbyMode`，未调用） | 32kHz | 关 | 按键 |

## 八、背光规格

| 档位 | `R_BacklightLevel` | 正常亮度 PWM | 占空比 | 休眠暗光 PWM | 占空比 |
|------|-------------------|-------------|--------|-------------|--------|
| 1 档（暗） | 1 | 76 | ~30% | 13 | ~5% |
| 2 档（中） | 2 | 153 | ~60% | 28 | ~11% |
| 3 档（亮） | 3 | 255 | 100% | 43 | ~17% |
| **灭** | — | ? **未实现** | — | — | — |

- PA5=0 → 正常亮度；PA5=1 → 自动切换休眠暗光
- PWM 频率 1kHz（源时钟 256kHz / 256 周期）
- `F_Backlight_Process()` 在主循环中轮询，仅在亮度变化时写硬件

## 十一、已知问题与注意事项

| # | 问题 | 位置 |
|---|------|------|
| 1 | 默认年份为 **2014**，新规格要求 2024 | `main.c` → `F_InitDateTime()` |
| 2 | 默认音量为 **1 档**，新规格要求 2 档 | 同上 |
| 3 | 背光缺"**灭**"档（仅 3 档循环） | `KeyScan.asm` → `Enable_BackLEDKey` |
| 4 | 计时键缺少"切换正/倒计时"和"长按**清零**" | `KeyScan.asm` → `Enable_TimerKey` / `?Enable_TimerlongSetKey` |
| 5 | 闹钟长按不区分开/关状态，一律进设置 | `KeyScan.asm` → `?Enable_AlmlongSetKey` |
| 6 | 设置超时约 **5 秒**，可能偏短 | `KeyScan.asm` → `C_SleepSec=0x0A` |
| 7 | `L_NoDisplayTimer` 中 `#0AAh` 作为数码管灭索引，`0xAA=170` 越界 | `lcd.asm` → `L_NoDisplayTimer` |
| 8 | 快短按计时键时语音可能连续播多次 | `KeyScan.asm` → 语音请求未做防抖/去重 |
| 9 | 关机态短按开关键功能已取消（`D_KeyRelDis` 控制） | 测试文档 #26 |
| 10 | 原 LVD 电池检测已改用 ADC 模拟量检测 | `F_DC_Det` 被注释，改用 ADC |
