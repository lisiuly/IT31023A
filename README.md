# IT31023A 正倒计时语音播报钟固件说明

本文按 `DEMO/` 当前代码整理，描述现有固件已经实现的行为，便于后续和规格书、测试记录、烧录版本核对。当前可烧录文件与 `DEMO/Release/IT31023A.hdb` 对应为 `IT31023A_V1.24_0x001BC3E0.hdb`。

## 1. 工程概况

| 项目 | 内容 |
| --- | --- |
| MCU | GPL815P 系列 6502 内核 |
| 工具链 | Generalplus GPIDE_6502 1.3.0，`gp65cc` / `6502_Asm` |
| 工程目录 | `DEMO/` |
| 工程文件 | `IT31023A.gpsln`、`IT31023A.gpproj`、`GPMakefile` |
| 输出文件 | `DEMO/Release/IT31023A.hdb` |
| 当前备份烧录文件 | `../烧录文件/IT31023A_V1.24_0x001BC3E0.hdb` |

主要代码模块：

| 模块 | 说明 |
| --- | --- |
| `main.c` | 上电初始化、主循环、低电关机流程、语音请求调度 |
| `Keyscan/KeyScan.asm` | 按键扫描、短按/长按/快加、开关机、闹钟/计时/背光操作 |
| `calendar/calendar.asm` | RTC 走时、星期/闰年、闹钟触发、贪睡逻辑 |
| `lcd/lcd.asm` | LCD 初始化、时间/日期/闹钟/计时/电量/充电显示 |
| `Timer/Timer.c` | 正计时、倒计时、背光 PWM |
| `UART/UART.c` | 语音模块串口协议、ASR 命令、播报队列、闹铃播放 |
| `ADC/ADC.asm` | PB7 电池电压采样和电量档位判断 |

## 2. 硬件与端口

| 功能 | 代码配置 |
| --- | --- |
| 系统时钟 | 正常运行 `D_SYS2M / D_CPUSysClkDiv1`，休眠使用 `D_SYS32K` |
| LCD | 6 COM x 48 SEG，VLCD 4.5V，电荷泵 8kHz |
| 按键 | PB1-PB6 掩码读取，关机态只保留 PB6 电源键扫描/唤醒 |
| 背光 | PA1 -> PWMIO1，1kHz PWM |
| 语音模块电源 | PA5 控制，低电平打开，高电平关闭或进入暗光状态 |
| 充电插入 | PA3，`F_KeepPA3InputPulldown()` 保持输入下拉 |
| 充满检测 | PB0，低有效 |
| 电池采样 | PB7 ADC LineIn，2:1 分压，VREF 3.2V，VSS 零偏校准 |
| 看门狗 | 主循环、ADC 等等待流程持续清狗 |

## 3. 上电默认值

| 项目 | 当前值 | 代码位置 |
| --- | --- | --- |
| 日期 | 2014-10-20 | `main.c` / `F_InitDateTime()` |
| 时间 | 00:00:00 | `main.c` / `F_InitDateTime()` |
| 星期 | 按默认日期计算 | `F_JudgeWeek()` |
| 音量 | 1 档，中音量 | `R_CurrentVolume = 0x01` |
| 背光 | 3 档，最高亮度 | `R_BacklightLevel = 0x03` |
| 闹钟 | 3 组时间均为 00:00，默认未开启 | `R_AlarmHour[]`、`R_AlarmMinute[]` |

## 5. 正常模式操作

| 操作 | 当前功能 |
| --- | --- |
| 短按闹钟键 | 循环查看当前闹钟组 1 -> 2 -> 3 -> 1；本轮第一次播放“闹钟查看” |
| 长按闹钟键 | 当前组已开启则关闭；当前组关闭则打开并进入该组闹钟设置 |
| 短按时钟键 | 正常模式无动作 |
| 长按时钟键 | 进入时间/日期设置，先设置年份，并请求播放“日期设置” |
| 短按正/倒计时键 | 空闲时切换计时显示模式；切到倒计时时进入 60:00 设置态；运行中暂停，暂停中继续 |
| 长按正/倒计时键 | 空闲时启动正计时；运行/暂停中清零；倒计时设置态退出不保存并清零 |
| 短按开关键 | 背光档位 1 -> 2 -> 3 -> 1 循环 |
| 长按开关键 | 开机/关机切换 |
| 短按 `+` 键 | 正常模式音量加，最大 2 档 |
| 短按 `-` 键 | 正常模式音量减，最小 0 档 |

## 6. 时间和日期设置

进入方式：正常模式长按时钟键。

| 操作 | 当前功能 |
| --- | --- |
| 短按时钟键 | 年 -> 月 -> 日 -> 时 -> 分 -> 保存退出 |
| `+` / `-` | 当前字段加减，长按支持快加/快减 |
| 切换月份 | 自动按当月最大天数修正日期 |
| 保存退出 | 清 `R_TimeFlashSet`，请求播放完整日期时间和“设置成功” |
| 超时退出 | 约 60 秒无操作后退出设置态 |

字段范围：

| 字段 | 范围 |
| --- | --- |
| 年 | 00-99，屏幕显示为 20xx |
| 月 | 1-12 |
| 日 | 1-当月最大天数，2 月按闰年修正 |
| 时 | 0-23 |
| 分 | 0-59 |

语音行为：

| 阶段 | 语音 |
| --- | --- |
| 进入日期设置 | “日期设置” |
| 切到小时设置 | “时间设置” |
| 保存退出 | 播报年月日时分 + “设置成功” |

## 7. 闹钟

当前支持 3 组闹钟，组号由 `R_CurrentGroup` 管理，开关位在 `R_AlarmOnOff` 中保存。

| 项目 | 当前实现 |
| --- | --- |
| 组数 | 3 组，bit0/bit1/bit2 对应 1/2/3 组 |
| 长按闹钟键 | 当前组开启则关闭；当前组关闭则打开并进入小时设置 |
| 设置流程 | 小时 -> 分钟 -> 天制 -> 保存退出 |
| `+` / `-` | 设置态调节当前字段 |
| 闹钟查看 | 正常模式短按闹钟键切换查看组 |
| 贪睡 | 闹钟响时按闹钟键进入贪睡，其他键关闭响铃/贪睡 |

天制定义以 `calendar.asm` / `lcd.asm` 为准：

| `R_DispAlmDay[group]` | 含义 | 触发日 |
| --- | --- | --- |
| `0` | 5 天制 | 周一至周五 |
| `1` | 6 天制 | 周一至周六 |
| `2` | 每天 | 周日至周六 |

贪睡参数：

| 参数 | 当前值 |
| --- | --- |
| 响铃最长时间 | `C_SnoozeTime1min = 60` 秒 |
| 贪睡间隔 | `C_SnoozeInterval = 5` 分钟 |
| 最大贪睡次数 | `C_SnoozeMaxCount = 3` |

## 8. 正计时和倒计时

计时状态主要由 `R_TimerFlag` 管理。

| 标志 | 含义 |
| --- | --- |
| `D_Timerstatus_just` | 正计时运行 |
| `D_Timerstatus` | 倒计时运行 |
| `D_Timerstatus_justpause` | 正计时暂停 |
| `D_TimerPausedCountDown` | 倒计时暂停 |
| `D_TimerModeCountdown` | 倒计时显示/模式 |
| `D_TimerSetstatus` | 倒计时设置曾被调整 |

按键流程：

| 操作 | 条件 | 当前功能 |
| --- | --- | --- |
| 长按计时键 | 空闲 | 从 00:00 启动正计时 |
| 短按计时键 | 正计时运行 | 暂停，播放“暂停计时” |
| 短按计时键 | 正计时暂停 | 继续，播放“继续计时” |
| 长按计时键 | 正计时运行/暂停 | 停止并清零 |
| 短按计时键 | 空闲且非倒计时模式 | 切到倒计时模式，进入 60:00 设置 |
| `+` / `-` | 倒计时设置态 | 调节分钟，范围 0-60，秒清零 |
| 短按计时键 | 倒计时设置态 | 启动倒计时，播放“开启计时” |
| 短按计时键 | 倒计时运行 | 暂停，播放“暂停计时” |
| 短按计时键 | 倒计时暂停 | 继续，播放“继续计时” |
| 长按计时键 | 倒计时运行/暂停 | 停止并清零 |
| 长按计时键 | 倒计时设置态 | 退出不保存并清零 |

计时结束：

| 模式 | 结束条件 | 结束动作 |
| --- | --- | --- |
| 正计时 | 60:00 | 停止正计时，进入响铃 |
| 倒计时 | 00:00 | 停止倒计时，进入响铃 |

语音 ASR 也支持倒计时开始、暂停、继续、结束，以及正计时开启。

## 9. 背光

| 档位 | `R_BacklightLevel` | 正常 PWM | 休眠暗光 PWM |
| --- | --- | --- | --- |
| 1 档 | `1` | 76，约 30% | 13，约 5% |
| 2 档 | `2` | 153，约 60% | 28，约 11% |
| 3 档 | `3` | 255，100% | 43，约 17% |

说明：

- 短按开关键只在 1/2/3 三档之间循环，没有“背光全灭”档。
- PA5 为低时使用正常亮度，PA5 为高时使用休眠暗光。
- 关机时禁用 PWM 并拉低 PA1。

## 10. 语音与 UART

语音模块由 PA5 上电，UART 协议帧由 `UART/UART.c` 维护。按键侧一般只置 `R_VoiceReq`，主循环等语音模块 `D_OpenReady` 后统一播放。

| 触发 | 语音 |
| --- | --- |
| 按键唤醒语音模块 | “我在” |
| 按键音 | `Di000_1_SP` 短滴声 |
| 闹钟查看 | “闹钟” + “查看” |
| 闹钟设置 | “闹钟” + “设置” |
| 日期设置 | “日期” + “设置” |
| 时间设置 | “时间” + “设置” |
| 时间设置完成 | 播报年月日时分 + “设置成功” |
| 计时开始 | “开启” + “计时” |
| 计时暂停 | “暂停” + “计时” |
| 计时继续 | “继续” + “计时” |
| 低电 | “低电报警” |
| 闹铃/计时到 | `Di001_2_SP` 循环播放 |

`R_VoiceReq` 位定义：

| 位 | 含义 |
| --- | --- |
| `0x01` | 闹钟查看 |
| `0x02` | 闹钟设置 |
| `0x04` | 日期设置 |

| `0x40` | 计时暂停 |

## 11. 电池、充电和低电关机

电池检测以 `ADC/ADC.asm` 为准，PB7 经 2:1 分压采样，VREF=3.2V，并用 VSS 做零偏校准。关机态和充电中不做电池 ADC 检测。

| 档位 | 阈值 | 显示 |
| --- | --- | --- |
| `D_BatLevel1` | 大于等于 4.0V | 3 格 |
| `D_BatLevel2` | 大于等于 3.8V | 2 格 |
| `D_BatLevel3` | 大于等于 3.6V | 1 格 |
| `D_LowPower` | 小于 3.6V | 电池闪烁并进入低电流程 |

充电显示：

| 状态 | 条件 | 显示 |
| --- | --- | --- |
| 未充电 | PA3=0 | 按电量档位显示 |
| 充电中 | PA3=1，PB0=1 | 电池格流水动画 |
| 充满 | PA3=1，PB0=0 | 电池框常显，内部格闪烁 |

低电关机流程：

1. 检测到 `D_LowPower` 后锁存低电流程，清除其他待播语音。
2. 若语音模块未 ready，先打开语音模块。
3. 播放一次“低电报警”。
4. 固定等待 `LOW_POWER_SHUTDOWN_TICKS = 640` 个 128Hz tick，约 5 秒。
5. 调用 `F_SystemPowerOff()` 自动关机。

插入充电会立即取消低电自动关机流程。

## 14. 当前注意事项

| # | 项目 | 说明 |
| --- | --- | --- |
| 1 | 默认日期 | 仍为 2014-10-20，如规格要求其他日期需改 `main.c` |
| 2 | 默认音量 | 仍为 1 档，如规格要求 2 档需改 `R_CurrentVolume` |
| 3 | 背光 | 已实现“熄灭后最低亮度亮着”的暗光逻辑，但没有用户可选的全灭档 |
| 4 | 电池阈值 | 当前低电阈值为 3.6V，不再是旧 LVD 注释里的 2.4V |
| 5 | 计时操作 | 当前短按计时键用于倒计时模式/设置/暂停/继续，空闲启动正计时由长按触发 |
| 6 | 设置超时 | 当前为约 60 秒，旧文档中“约 5 秒”已不适用 |
| 7 | 天制命名 | 代码实际为 0=5 天制、1=6 天制、2=每天，注意不要按旧注释写反 |
| 8 | 构建路径 | `GPMakefile` 含本机 GPIDE 绝对路径，换电脑后需重新生成或修改路径 |
